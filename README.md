# Riff

**Viral content engineered for your product.**

AI social marketing studio: Product DNA → viral hooks → platform-native posts (TikTok, Instagram, X, LinkedIn, Reddit) → connect & schedule.

Built to beat generic AI caption tools — sharper organic execution than growth-planner apps and paid-ad factories.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) → `/studio`

### Optional AI

Set `AI_GATEWAY_API_KEY` for live model generation. Without it, the built-in demo viral engine still runs the full flow.

## Stack

- Next.js 16 (App Router) + Tailwind CSS 4
- Vercel AI SDK
- Framer Motion + Syne / Manrope
